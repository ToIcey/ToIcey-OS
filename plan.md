# ToIcey OS - Technical & Aesthetic Blueprint

ToIcey OS is a high-performance, Arch-based Linux distribution designed for developers and AI enthusiasts. It features a unique "Sub-Zero" aesthetic and integrated AI logic.

## Aesthetic: Sub-Zero Crystalline
- Theme: Crystalline glassmorphism with frost-white, ice-blue, and deep sapphire tones.
- UI Elements: High-density frosted glass effects, frozen borders.
- Animations: "Snap-Freeze" logic for window transitions.
- Desktop: Hyprland with a snowflake-inspired configuration.

## Intelligence: Ice-Core AI
- Primary Model: Qwen2.5-Coder-7B (integrated into the workspace).
- Capabilities: Uncensored coding logic, sub-zero status indicators.
- Environment: Ollama pre-installed with optimized model weights.

## Developer Toolchain
- Languages: Python, Node.js, C++.
- Containers: Docker and Podman ready.
- IDE: VS Code with custom frozen theme.
- Build System: GitHub Actions Cloud-Build engine for ISO generation.

## Deployment
Use the toicey-setup.sh script to configure the environment or build the official ISO via the included GitHub workflow.
